组合结构化文档、文档视图、侧边栏控制工具和讨论工作台，统一安装与启停。

## 能做什么

- 结构化文档负责节点、内容修改、保存和撤销。
- 文档视图负责 Markdown、思维导图和表格，以及视图切换。
- 侧边栏控制工具负责文件选择、打开、展示和切换。
- 办公讨论工作台组织参考材料与固定目标，展示讨论中的文档状态。

## 安装

本地版本 **0.2.1-rc.2+rev.1**，要求 DSH Desktop **0.2.1-rc.2** 与 Better Sidebar **0.28.0**。源码仓库为 [dsh-office-bundle](https://github.com/irvingzhang0512/dsh-office-bundle)。目前正在准备公开分发，固定预构建包尚未发布；源码入口不包含全部生成产物，不能将仓库链接直接当作可用安装包。现有本地安装仍由维护者提供完整 tgz。已有单独组件时，使用固定包接管流程切换，避免重复安装入口。

1. 确认已安装并启用要求版本的 Better Sidebar。
2. 在“插件 → 添加插件 → 安装第三方插件”填写本包绝对路径，核对名称和完整版本。
3. 启用后按宿主提示重启；进入套件详情，核对四个成员与外部依赖的状态。

## 配置

套件没有额外业务配置。进入插件详情管理各成员原有设置和子开关；总开关关闭整套，重开保留各自选择。

## 第一次使用

在一个可写工作区打开会话，让 Agent 先列出可用材料，再明确指定一个结构化目标文档。例如：“先列出当前文件夹里的文档，帮我选择参考材料；在我确认目标后再开始整理。”确认文件后，可要求：“把刚才讨论确认的事项写入目标文档，并切换到思维导图查看。”检查目标文档内容、视图及工作台状态一致；浏览参考文件不会替换已经固定的目标。

## 使用边界

套件不复制文档库、模型工具或Skill；不新增会议／项目流程。组件停用可能使依赖它的工作台等待。停用或卸载不删除文档、材料或会话，也不会自动恢复安装前的独立Bundle入口。

## 常见问题

### 部分组件没有运行

刷新详情状态，先检查子开关、Better Sidebar版本和依赖提示。版本不符时由维护者恢复固定组合，不使用兼容豁免。

### 已安装独立组件

通过维护者的接管流程移除重复直接安装入口，保留原条目配置与业务数据；独立组件仍可在另一套组合中单独使用。
